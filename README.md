# NEXORA CAREERS

منصة توظيف وإدارة فرص العمل.

## الحالة الحالية

يحتوي المستودع على نسخة مرجعية من التطبيق المنشور، إضافة إلى بداية فصل المصدر إلى وحدات:

- `worker/worker.js` — نسخة مرجعية محفوظة من Worker الإنتاج كما كانت عند بدء النقل.
- `src/worker.js` — نقطة دخول منظمة تستورد صفحات الواجهة من الوحدة المنفصلة.
- `src/frontend/public-page.js` — صفحة الموقع العامة.
- `src/frontend/admin-page.js` — صفحة لوحة الإدارة.
- `src/backend/auth-api.js` — إنشاء الحساب وتسجيل الدخول والخروج.
- `src/backend/public-api.js` — عرض الوظائف والدورات والتفاصيل.
- `src/backend/account-api.js` — الملف الشخصي والدعم والاشتراكات والتقديم.
- `src/backend/admin-api.js` — واجهات لوحة الإدارة.
- الموقع المنشور: https://nexora-careers.m7njordan.workers.dev/
- لوحة الإدارة: https://nexora-careers.m7njordan.workers.dev/admin

## الخدمات المرتبطة

يعتمد النشر الحالي على Cloudflare Worker مع ربط الموارد التالية:

- D1 binding باسم `DB` لبيانات التطبيق.
- KV binding باسم `STORE` للتخزين المفتاحي.

**تنبيه:** ملفات هذا المستودع لا تحتوي على بيانات قاعدة البيانات أو قيم الأسرار أو مفاتيح الحساب. لا تضع أي مفاتيح سرية أو بيانات مستخدمين في Git.

## قاعدة البيانات

راجع [docs/database-schema.md](docs/database-schema.md) لبنية D1 التي تم التحقق منها دون تعديل البيانات.

## تشغيل التطوير

المستودع يتضمن نقطة دخول Worker معيارية وإعداد Wrangler في `wrangler.toml`. استخدم `npm install` ثم `npm run dev` للتشغيل المحلي. تتضمن الاختبارات فحص الصحة والواجهات العامة وقيود عرض الوظائف والدورات.

## خطة التنظيم

1. تثبيت النسخة الحالية في Git كمرجع آمن.
2. فصل الواجهة عن منطق API والخدمات (تم فصل صفحات الواجهة وواجهات الحسابات والقراءة والإدارة).
3. توثيق مخطط D1 ومسارات API دون تضمين بيانات حقيقية.
4. إضافة اختبارات للوظائف الأساسية (أضيفت اختبارات دخان وفحوصات CI، ويلزم تشغيلها والتحقق من نتائجها).
5. الانتقال التدريجي إلى بنية وحدات مع الحفاظ على سلوك الموقع المنشور.

لا يتم نشر أي تغيير إلى الإنتاج تلقائيًا بمجرد رفعه إلى هذا المستودع.
