# NEXORA CAREERS

منصة توظيف وإدارة فرص العمل.

## الحالة الحالية

هذا المستودع يحتوي على نسخة مصدرية من Cloudflare Worker المستخدم حاليًا في الإنتاج:

- `worker/worker.js` — التطبيق الحالي، ويضم واجهة الموقع وواجهات API ولوحة الإدارة.
- الموقع المنشور: https://nexora-careers.m7njordan.workers.dev/
- لوحة الإدارة: https://nexora-careers.m7njordan.workers.dev/admin

## الخدمات المرتبطة

يعتمد النشر الحالي على Cloudflare Worker مع ربط الموارد التالية:

- D1 binding باسم `DB` لبيانات التطبيق.
- KV binding باسم `STORE` للتخزين المفتاحي.

**تنبيه:** ملفات هذا المستودع لا تحتوي على بيانات قاعدة البيانات أو قيم الأسرار أو مفاتيح الحساب. لا تضع أي مفاتيح سرية أو بيانات مستخدمين في Git.

## تشغيل التطوير

النسخة الحالية Worker مباشر وليست مشروع واجهة Vite منفصلًا بعد. قبل إضافة إعدادات تشغيل أو نشر آلي، يجب مراجعة المصدر وتقسيمه واختبار المسارات الحالية مع الحفاظ على ربط D1 وKV.

## خطة التنظيم

1. تثبيت النسخة الحالية في Git كمرجع آمن.
2. فصل الواجهة عن منطق API والخدمات.
3. توثيق مخطط D1 ومسارات API دون تضمين بيانات حقيقية.
4. إضافة اختبارات للوظائف الأساسية.
5. الانتقال التدريجي إلى بنية وحدات مع الحفاظ على سلوك الموقع المنشور.

لا يتم نشر أي تغيير إلى الإنتاج تلقائيًا بمجرد رفعه إلى هذا المستودع.
